# Privacy Policy — Foragers

**Effective date:** 2026-08-15
**Developer:** Disketaa
**Contact:** disketaa.off@gmail.com

This Privacy Policy explains what information the Game handles and how. Foragers is a single-player, offline-first game. It does **not** operate its own servers and does **not** transmit collected data to the developer.

## 1. Information We Collect

The Game does not collect personal information through servers or accounts. The only data handled is described below and stays on your device.

## 2. Information Stored Locally

- **Game settings** (such as video, audio, and control options) are saved locally in the save directory (`Options.txt`).
- **Diagnostic logs** (such as load timings and asset/error messages) are saved locally in the save directory (`Logs/`). These logs may include the local file-system path to the save directory, which can contain your Windows user-profile name. They do not include account identifiers, IP addresses, or gameplay content.
- **Debug chat history** (commands typed into the optional in-game debug console) is saved locally (`ChatHistory.txt`) and may contain arbitrary text you entered.

## 3. Information We Do Not Collect

The Game does not collect or transmit: your name, email, IP address, device identifiers, account information, location, analytics, telemetry, or crash reports to any server. Gameplay statistics (such as experience, level, and satiety) exist only in memory during a play session and are not saved or sent anywhere.

## 4. Discord Rich Presence

Discord Rich Presence is currently **enabled** in the shipped configuration. When active, the Game sends activity information (such as the current game scene, process ID, and session timestamp) to the Discord client running locally on your device via local inter-process communication. From that point, Discord processes this data under its own Privacy Policy (https://discord.com/privacy). The Game does not receive data from Discord.

## 5. Third-Party Software

The Game is built on the LÖVE 2D engine. The engine's license and notices are distributed with the Game (see "Licenses" in-game) and are separate from this Privacy Policy. No third-party analytics, advertising, or tracking SDKs are included.

## 6. Data Deletion

All local data is stored in the operating-system save directory for the Game (typically `%APPDATA%/Foragers` on Windows). You can delete it at any time by removing that folder. Uninstalling the Game does not automatically remove the save directory.

## 7. Children's Privacy

The Game is not directed at children under 13 and does not knowingly collect personal information from children. If you believe a child has provided personal information through the Game, contact the developer using the address below.

## 8. Changes to This Policy

The developer may update this Privacy Policy from time to time. The current version is always available at the URL referenced in the Game and the project repository.
